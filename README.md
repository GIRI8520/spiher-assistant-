# 🚀 SPIHER BCA Assistant - AI Campus Inquiry Chatbot

An AI-powered conversational web application built for the Department of Computer Applications at SPIHER, designed to provide real-time, multilingual student assistance (English, Tamil, and Tanglish).

---

### 🌐 Live Application
👉 [View Live Demo](https://spiher-assistant-f3sljmttc-giri8520s-projects.vercel.app/)

---

### ✨ Key Features
* **Multilingual Support:** Seamlessly handles queries in English, Tamil, and Tanglish.
* **Smart Institutional Datasets:** Pre-loaded with HOD details, faculty directories, lab timings, research metrics, and department FAQs.
* **Modern UI/UX:** Built with a clean, responsive layout featuring dynamic cards and performance metrics.

---

### 🛠️ Tech Stack
* **Frontend:** React, TypeScript, Vite, Tailwind CSS
* **AI Integration:** Google AI Studio / Gemini API (`gemini-3.6-flash`)
* **Deployment & Version Control:** Git, GitHub, Vercel
